Aula 1: Introdução ao Pensamento Computacional e Swift

Nesta primeira aula, o foco foi estruturar o pensamento lógico antes de escrever qualquer código. Revisamos os conceitos iniciais sobre o que são variáveis, como o computador aloca memória para elas e os tipos de dados primitivos. Essa base de lógica de programação é essencial para começar o desenvolvimento no ecossistema mobile com Swift.
